# 鹏基石材 · 视频文稿库

鹏基石材（石材小王子）视频口播文稿总库，共 42 篇，已加标点符号并整理为单文件 HTML。

- 内容来源：`/Users/Zhuanz/Downloads/鹏基石材/` 下 42 个语音转写 txt
- 分类：工艺与技术 / 工地管理 / 创业与人生 / 项目与实景 / 材料科普
- `index.html`：完整文稿列表、筛选和阅读；手机上可点击「筛选」打开侧栏
- `directory.html`：按主题分组的目录页，支持搜索和直达正文
- 两个页面均无外部依赖，可离线打开

更新 `index.html` 中的文稿数据后，运行 `python3 build_directory.py` 同步生成目录页。
